How to set up Google Sheets (5 steps)
1. Go to sheets.google.com → Create new sheet → Name it "Truckeya Shipments"
2. Click Extensions → Apps Script → Delete existing code → Paste the script from the truckeya-google-script.js file
3. Click Deploy → New Deployment → Web App
4. Set "Who has access" → Anyone → Click Deploy → Authorize
5. Copy the URL → Paste it above → Click Save & Connect
